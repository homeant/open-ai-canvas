# 画布智能整理

画布底部视图控制区、多选工具栏和右键菜单均提供「智能整理」。点击文字按钮立即整理；右侧箭头可以选择其他方式。无需调用模型，也不消耗生成额度。

有选区时只整理选中节点所属的组合；没有选区时整理整张画布。菜单会说明当前范围。选中背板、文件夹、批次或图层组中的节点时，组合整体移动，内部位置与归属保持不变；任何成员锁定都会保护整组。

| 方式 | 行为 |
| --- | --- |
| 智能整理 | 关联节点按连线从左到右排布，不同创作链路分别布局，独立节点按媒体类型归整；同一镜头的素材优先放在一起 |
| 仅消除重叠 | 尽量保留当前位置，只移动过近的节点 |
| 按类型整理 | 按文本、图片、视频、音频分区，使用节点实际尺寸排列 |
| 按镜头顺序 | 按已有章节、场景和镜头编号排列，同一镜头的素材放在同一行；优先读取真实分镜行绑定，并从明确来源推导生成结果所属镜头 |
| 按连线整理 | 按来源到结果的方向分层，独立链路分开摆放 |
| 宫格／横向／纵向排列 | 按指定形式展开，避让其他节点 |

无镜头信息的节点使用稳定次序排列，不从提示词猜测镜头编号；多个分镜脚本中相同的镜头编号保持各自归属。循环连线不会导致布局卡死，整理不修改原有连线。

整理只提交节点位置，保留内容、尺寸、媒体比例和连接关系。锁定组合与选区外节点保持原位，其他节点绕开它们。折叠组合里的隐藏成员随组合平移，但不会撑大可见布局或整理后的取景范围。组合内部原本的叠放会被保留，例如图片图层的重合。

整理完成后，视图定位到整理区域，提示移动数量和保留的锁定组合数量。一次撤销恢复整次整理，也可以重做；不会与紧邻的文字编辑或拖动合并。继续编辑后，提示里的快捷撤销会关闭，仍可使用画布原有的撤销／重做。重复执行相同整理不会持续改变已经整齐的位置。

普通创建、文件夹创建、复制、粘贴、上传、素材插入、从连线创建节点和分镜输出节点会为新节点寻找附近空位，保留已有节点的位置。媒体生成按完整结果组范围避让，保持来源到结果的向右或向下落位。替换已有媒体仍保留其原位；保存沿用画布既有的本地缓存与服务端同步状态，整理成功提示不代表服务端已经持久化。

## 实现边界

前端文档级组合与镜头规划位于 `web/src/lib/canvas/canvas-smart-layout.ts`，基础分层与媒体泳道位于 `canvas-layout.ts`。后端 Agent 的基础布局位于 `backend/internal/canvas/layout/graph.go`，两端通过同一份 `testdata/canvas-layout.json` 核对坐标与重复整理稳定性。Agent 工具继续使用自己的可移动节点范围、快照校验与审批合同，不会因前端新增菜单方式而改变工具入参。
