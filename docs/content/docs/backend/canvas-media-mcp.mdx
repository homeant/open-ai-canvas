外部 `/api/mcp` 使用登录授权账号，不接受客户端指定用户。上传与正式采用、人工验收分别处理；资源 `ready` 仅表示文件可用。

## 本地文件上传

1. `begin_media_upload` 提交 `fileName`、`kind=image|video|audio`、字节 `size`、完整文件 `sha256` 与 `idempotencyKey`。返回 `uploadId`、1 MiB `chunkSize`、`chunkCount` 与 90 分钟截止时间。
2. `upload_media_chunk` 提交 `uploadId`、从 0 开始的 `index`、`dataBase64` 与分片 `sha256`。相同内容重传安全，同序号不同内容拒绝。
3. `get_media_upload` 读取已收分片及其哈希。客户端只补缺片；不要将大文件内容写入聊天或日志。
4. `complete_media_upload` 校验完整大小、SHA-256、文件真实类型，探测尺寸／时长并保存自有资源；完成重试返回同一资源 ID。PNG/JPEG 用图片解码，MP4/WAV 依赖服务端 ffprobe。探测失败不会登记成成功。
5. `abort_media_upload` 释放未完成上传的配额并删除该会话分片；不能用它删除已完成资源。

复用浏览器上传的单文件、日上传和总存储配额；每账号最多 32 个活动会话，单请求小于 MCP 的 4 MiB 上限。幂等键不能换文件复用。文件只保存在服务端 dataDir 的私有 staging 目录，客户端路径不会成为服务端文件路径。上传日志在同一 dataDir 下持久保存，服务重启后可续传；当前只适用于单后端实例，跨实例续传需要共享 staging 存储。过期会话须取消后重新开始。

上传不会修改短剧分镜、采用角色／道具设定、替换正式视频或自动通过 QA。创建独立审片节点需要另一次明确操作。
