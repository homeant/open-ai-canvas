# 渠道、模板与批量配置

后台「渠道与模型」按 API 网站组织连接配置。一个网站可以包含多个 Key 分组，每个分组独立读取模型、选择调用协议、设置能力和积分价格。

## 网站与 Key 分组

先新增网站，填写 API Base URL 和模型目录格式，再在网站内新增 Key。目录格式只决定如何读取模型列表，模型的图片、文本、视频或音频调用协议仍分别设置。

- 网站共享 Base URL、目录格式、出站代理和允许共享的请求头；Key 凭据、私有请求头、模型和价格属于各自分组。
- 分组标题提供启用 / 停用入口，拖动排序手柄调整顺序。停用保留配置，后续可以重新启用。
- 修改网站公共连接会提示受影响的分组数量；保存后同步这些分组的公共连接，不替换凭据或模型价格。
- 网站按完整连接配置归组，保留版本和租户路径，不只按域名合并。只有空网站可以删除。
- 原有 JSON 导入与导出入口保留；导出不包含 API Key，导入的新分组先保持停用，补齐凭据后再启用。

读取目录会显示新增、仍存在和已缺失的型号。目录中缺失的型号不会自动删除，也不会因为再次读取目录而覆盖已设置的能力、价格或启停状态。

同一网站、型号和能力类型可复用先前明确选择过的协议。历史有冲突或协议不可用时，需要重新选择。协议建议不携带能力限制，各 Key 支持的参数仍由自己的模型配置决定。

## 使用 ChatGPT 方案额度的个人渠道

本机运行的开源影策可以在「渠道与模型」使用「使用 ChatGPT 登录」连接本人账号。授权在系统浏览器完成；后端将 OAuth 令牌加密保存到系统设置，按账号可用目录展示模型，管理员只加入自己需要的模型。该渠道只有完成授权的影策账号能在模型目录和任务中使用，其他站内用户与管理员不可借用其额度；通用系统渠道中转不接受此渠道。

调用使用 `https://api.openai.com/v1/responses` 的 OAuth Bearer 令牌，`store: false`、`stream: true`，不是读取桌面 Codex App 的登录文件，也不是普通 API Key 计费。影策按本人使用设置为 0 积分；ChatGPT 方案自身的用量限制仍由 OpenAI 执行。断开连接时清除本机令牌和渠道，并尝试撤销远端会话；若远端撤销未确认，需到 ChatGPT 设置检查连接。

当前授权入口只支持浏览器与影策后端位于同一台电脑的本机部署。远程服务器要使用官方自托管 VM 流程，不能让浏览器访问服务器自己的 `127.0.0.1`。请求仅支持官方此方案允许的 Responses 文本及函数工具能力；不支持图像生成、音视频和托管工具。参考 [OpenAI 开源应用授权](https://developers.openai.com/siwc/token-sharing-open-source) 与 [预览期请求约束](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)。

## 能力与积分模板

模型编辑页的「能力与参数」和积分配置处提供模板选择、应用、新增、编辑和保存当前配置。能力模板支持文本、图片和视频，积分模板按模型类型区分。自建模板保存在当前浏览器的当前账号下，不会自动同步到其他浏览器或账号。

能力模板只保存能力和引用限制，不绑定调用协议，也不保存模型身份、价格或连接凭据。应用模板先更新当前表单，模型保存时才写入服务端；撤销应用同样只影响草稿。

积分模板保存计价货币、价格档及相关计费设置，不保存独立上游型号。应用后使用目标模型的上游型号。编辑模板不会自动修改已应用过它的模型。

价格条件必须与最终能力配置相符。例如，能力只有 1K、2K 时，不能保存仅匹配 4K 的价格档。发生冲突时表单显示具体档位与字段，修正后再保存。价格未填写时不能被当成免费；免费必须明确设置。

声明式图片模型的价格档可使用 `selector.referenceImageCount` 按实际参考图张数计价，取值为非负整数。引用张数未配置对应档位时，请求不会误用其他张数的价格档；需要覆盖全部允许的张数时，应逐档配置。

## 统一批量配置

在某个 Key 的模型列表或全部模型列表中勾选模型，打开「批量修改」，一次配置：

- 调用协议、能力模板和积分模板；
- 模型展示名、备注；
- 模型启用状态及价格档的「可供用户使用」。

混选不同类型时，文本、图片、视频、音频分别选择对应协议与模板。已有类型保留，尚未设置类型的新模型可以在弹窗内初始化，不必逐个进入编辑页。不选择的字段保持原值。

「可供用户使用」控制所选模型的全部价格档，与模型启用独立；关闭不会清空金额、成本，也不会改为免费。

保存会先组合协议、能力、模板及启停等变更，再校验最终结果。任何模型冲突或被其他管理员更新时，整批不写入，刷新配置后再提交。成功保存但列表刷新失败时提示手动刷新，不自动重复提交。

## 模型切换与图片版本预览

画布、创作表单和相关工作台切换图片或视频模型时，保留兼容的比例、分辨率、时长、帧率和音轨设置；不适配的值按目标模型能力调整或省略。保存、重新打开、报价和生成请求使用同一组适配结果。切换模型不会自动改选其他型号，也不会自动提交生成任务。

图片生成总张数沿用上游拆单规则：单次只支持一张的模型仍可生成多张，平台按单次上限拆成任务。模型参数适配不等于已有报价仍有效，生成前仍检查实际模型、规格和价格。

图片版本预览按图片原比例完整显示。双击打开浮层后，可滚轮缩放、拖动查看；关闭浮层保留当前选择的版本。
