# 待办

## 真实音视频人物与嘴部自动检测

- 按镜头窗口的实际视频 ASR、人工声源／嘴部 QA 和独立音轨合成候选已实现。自动说话人识别、声源身份验证、画外声闭口与音画同步检测尚未实现；后续须接入可验证的实际音视频检测器，输出版本绑定证据和未知状态，不能由台词相同或角色名称推断通过。
- 原生人声分离与保留原生音乐／环境音尚未实现。现有替换路径明确丢弃整个原生音轨，需要独立补音乐和环境音；不能宣称已提供无损人声删除。

## 预演动作的关节与接触约束

- 逐镜骨骼语义操作、姿态连续插值与标准人偶手掌／脚底标记的区间 CCD 已实现，待真实动作验收。后续增加关节限位、肘膝朝向控制、全身平衡和更完整的起身编排，不把根节点翻转当作真实起身。
- 增加接触约束的 UI 编辑与精确几何碰撞检测。当前标记残差与世界坐标包围盒不能确认皮肤接触、无穿模或动作物理正确性。
